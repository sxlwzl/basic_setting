## 四、换机重装建议顺序

1. 登录 Apple ID → App Store「已购项目」批量安装 A 组 9 个应用。
2. 安装 Xcode Command Line Tools：`xcode-select --install`。
3. 安装 Homebrew，把本目录的 `Brewfile` 放到新机，执行 `brew bundle`（会自动装好 8 个 formula、17 个 cask 与 4 个 npm 全局包）。
4. 安装 Adobe Creative Cloud 桌面端 → 登录 Adobe ID → 安装 Acrobat / Photoshop 2024 / Audition 2024。
5. 逐个官网下载 C 组应用；付费软件（Rhino 8、Transmit、BetterZip、Navicat、DriveDx、Paragon NTFS、iStat Menus）先确认许可证可转移，必要时在原机反激活。
6. 补装输入法与系统扩展，重新授权 Paragon NTFS 等内核扩展，恢复输入法词库。
7. 迁移配置与数据：VS Code 扩展（`code --list-extensions > extensions.txt`）、iTerm 配置、OBS 场景、`~/.zshrc`、SSH 密钥、Git 配置、浏览器书签、微信聊天记录。

## 五、需要特别注意

- **架构**：本机为 arm64。换机若仍为 Apple Silicon 可直接沿用；若为 Intel 机型，Homebrew 路径为 `/usr/local`，Brewfile 仍可用，但需重新核对驱动类软件（Paragon NTFS）的兼容性。
- **版本偏旧**：Microsoft Edge 120、WPS cask 3.2、CocosCreator 3.8.8 等为旧版本，换机建议直接装最新稳定版，不必强求版本一致。
- **F 组历史记录**：pkg 收据与部分 cask 收据不等于软件仍在。建议换机前在原机用 `brew bundle cleanup` 或直接编辑 Brewfile 删除不需要的 cask 行，避免装回已弃用软件。
- **Brewfile 中的自定义 tap**：`tap "homebrew/services", "https://gitee.com/cunkai/homebrew-services.git"` 指向第三方镜像，换机时若该地址不可用，可改为 `tap "homebrew/services"` 或删除该行。
- **不含内容**：本清单只记录软件与版本，不含文档、项目文件、浏览器数据、聊天记录等个人数据，迁移时需另行备份。
